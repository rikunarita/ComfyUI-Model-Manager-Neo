# ComfyUI‑Model‑Manager‑Neo 使い方ガイド（日本語）

> 姉妹ドキュメント: [English](USAGE-EN.md) · [中文](USAGE-ZN.md)
> 本文中のスクリーンショットは [`docs/screenshots/`](screenshots/) にあります
> （各ファイルの一覧は[スクリーンショット](#スクリーンショット)参照）。

ComfyUI‑Model‑Manager‑Neo は、ComfyUI にモデルの**閲覧・ダウンロード・
アップロード・編集**機能を追加するカスタムノードです。ComfyUI プロセスの外には
一切出ません。バックエンドは ComfyUI サーバ内の `aiohttp` ルート群、フロントエンドは
ページに注入される単一のバンドル済み Vue 3 アプリです。

## 1. インストール

```bash
cd ComfyUI/custom_nodes
git clone https://github.com/rikunarita/ComfyUI-Model-Manager-Neo.git
```

ComfyUI を再起動してください。Python 依存（`huggingface_hub`・`hf_xet`・
`markdownify`）は初回起動時に自動インストールされ、Web バンドルはリポジトリに
同梱されているため、**実行に Node.js は不要**です。

手動インストールの場合は、リポジトリのアーカイブをダウンロードして
`ComfyUI/custom_nodes/` に展開し、フォルダ名が
`ComfyUI-Model-Manager-Neo` であることを確認してください。

## 2. マネージャーの開き方

入り口は 4 つありますが、どれも同じ動作です。

| 入り口                                      | 場所                                     |
| ------------------------------------------- | ---------------------------------------- |
| **トップバーの「Model Manager Neo」ボタン** | ComfyUI トップバー（歯車のとなり）       |
| **レガシーメニューのボタン**                | 旧 UI のメニューコンテナ（存在する場合） |
| **Extensions メニュー**                     | `Extensions → Model Manager Neo`         |
| **コマンドパレット**                        | `Comfy.ModelManager.Open` コマンド       |

マネージャーは**非モーダル**です。ComfyUI の上に浮かびますが、キャンバスは
完全に操作可能なままなので、閲覧しながらグラフへモデルをドラッグできます。
ウィンドウはタイトルバーで移動、端・角でリサイズ、⤢ ボタンで最大化できます。
複数ウィンドウを同時に出せ、クリックしたものが最前面に来ます。

> ローディング表示は**対象パネル内に限定**されます。リクエスト中は該当ウィンドウ
> だけがぼかされ、キャンバス・トップバー・他のウィンドウはそのまま使えます。
>
> ![パネル限定ローディング](screenshots/loading-panel.png)

## 3. 2 つのレイアウト

ヘッダー先頭のボタン（グリッド ⇄ フォルダ）で切り替えます。既定は
**設定 → Model Manager Neo → UI → Flat Layout** で変えられます。

### フラット表示

全種別・全モデルを 1 つのグリッドにまとめ、ツールバーを備えます。

- **検索** — 複数トークンは AND 条件、`*` はワイルドカード
  （`*anime*` なら anime を含む名前に一致）。トークンはファイル名**または**
  サブフォルダに一致します。
- **種別フィルタ** — `すべて` または単一のモデル種別。
- **並び替え** — 名前順 / サイズが大きい順 / 作成日が新しい順 / 更新日が新しい順。
- **カードサイズ** — 特大 / 大 / 中 / 小、または**カスタムサイズ**
  （幅・高さスライダーのダイアログ。ComfyUI の設定に保存されます）。

![フラット表示](screenshots/view-flat-dialog.png)

### フォルダ表示

ブレッドクラム付きのファイルマネージャ風ツリーです（各階層に小さなフォルダ
グリフが付きます）。フォルダをダブルクリックで中へ、ブレッドクラムまたは ↑
ボタンで戻ります。モデルを右クリックするとコンテキストメニュー（**開く**）が出ます。
ブレッドクラムは現在開いているフォルダを必ず読みやすい形で残します:
幅が足りないときは途中の階層から省略表示され、ツールバーはコントロールを
切り捨てず、フラットビューと同じ規則で縦に積まれます。

![フォルダ表示](screenshots/view-folders-dialog.png)

検索欄の横には**フォルダを追加**ボタン(フォルダプラスアイコン)があります。
任意の名前を入力すると、現在開いているディレクトリの中にフォルダを作成
できます(`_ZNN` / `_DeltaZNN` で終わる名前は ZipNN 専用で予約されています)。
検索欄の横には**並び順**と**カードサイズ**のセレクトもあります ― フォルダ表示は
「フラット表示を1フォルダに絞り込んだもの＋フォルダ専用の追加機能(上の階層へ
戻る・フォルダ作成・フォルダ圧縮など)」という設計で、モデルカードの見た目と
機能(ホバーで現れるノード追加/コピー/ワークフロー/モデルページボタンを含む)は
両レイアウトで完全に同一です。

どちらのレイアウトでも、ヘッダーの目アイコンで**隠しファイルの表示/非表示**
（名前が `.` で始まるファイル・フォルダ）を切り替えられます。

## 4. モデルカード

![モデルカード](screenshots/view-flat.png)

- **プレビュー** — 画像またはループ動画。プレビューの無いモデルはガラス製の
  **NO PREVIEW** アートワークを表示します。
- **チップ**（右下） — モデル種別とファイルサイズ。カードサイズに追従します。
- **スタートグル**（右上・すべてのカード） — 未スター時は輪郭スター、スター済みは
  塗りつぶしの黄色いスター。クリックで切替。スター済みのモデル/フォルダは常に
  先頭へ並ぶ。
- **ZipNN コーナーボタン**（右上・スターの隣） — ZipNN アートワークそのままのボタン。
  1 クリックで圧縮(圧縮済みは反転表示で解凍)を確認画面付きで実行。フォルダ
  カードではバッチ圧縮/解凍になります。
- **フォルダカード** — 手描きのガラスフォルダ。ポインタを 1 秒置くと開き、
  離れて 1 秒後に閉じます。通り過ぎただけでは反応しません。
- **ホバーアクション**（フラット表示・大きいカード） — **ノード追加**・
  **ノードコピー**・**プレビューからワークフロー読込**。
- **グラフへドラッグ** — 任意のカードをキャンバスへドラッグ:
  - 空きキャンバス: 対応するローダーノードを作成し、モデルを選択済みで投入
  - 既存ノードの上: 一致する combo 入力へ投入
  - _embedding_ をテキストエリアへ: `(embedding:name:1.0)` を追記
  - **プレビュー画像**をドラッグ: 画像に埋め込まれたワークフローを読込
- **ダブルクリック / クリック** — モデル詳細ウィンドウを開きます。
- **ツールチップ** — カードにポインタを置くと絶対パスが表示されます。

## 5. モデル詳細と編集

![モデル詳細](screenshots/model-info.png)

プレビュー（複数あればカルーセル）、基本情報テーブル、2 つのタブを表示します。

| 行                                   | 意味                                                        |
| ------------------------------------ | ----------------------------------------------------------- |
| モデル種別                           | ComfyUI のモデルフォルダ群                                  |
| **ディレクトリ**                     | **末尾 `/` 付き**の絶対ディレクトリ（例: `…/models/unet/`） |
| ファイル名                           | 拡張子を除いた名前                                          |
| ファイルサイズ / 作成日時 / 更新日時 | ファイルシステムの情報                                      |

### 閲覧

- **Description タブ** — モデルと同名の `*.md` に保存された Markdown を描画。
  リンクは新規タブで開きます。
- **Information タブ** — モデルに記録された情報を一目で読むための
  読取専用の表です。ノート先端の YAML フロントマター（Civitai /
  HuggingFace ダウンロードが書き込むもの）が作者・ベースモデル・
  全ハッシュ値（`AutoV1` … `SHA256_12`）・形式と精度・クリック可能な
  モデルページリンク・**すべて**のプレビュー画像 URL へと展開され、
  パーサーの知らないキーはキー名のまま表の末尾に並びます。フロントマター
  の無いモデルは safetensors ヘッダから直接読んだ `__metadata__` を
  そのまま表示します（バックグラウンドのスキャンやキャッシュは一切ありません）。

### 編集

**鉛筆アイコン**で編集モードに入ります（ウィンドウがフォームになります）。

![編集モード](screenshots/model-edit.png)

- **モデル種別** — 現在の ComfyUI に実際にフォルダが存在する種別のみを表示。
- **ディレクトリ** — 読取専用フィールドと**フォルダボタン**。ボタンは全ベースパスと
  サブフォルダのツリーを持つネスト된フォルダ選択ダイアログを開きます。

  ![フォルダ選択](screenshots/folder-picker.png)

- **ファイル名** — **フォルダ指定を受け付けます**。`subfolder/my-model` と入力して
  保存すると `…/models/unet/subfolder/` に格納されます（無いフォルダは作成）。
  `\ : * ? " < > |` と、空・`.`・`..` セグメントは拒否され、バックエンドでも
  パス侵入検査を再実施します。
- **プレビュー** — `デフォルト`（カルーセル）/ `ネットワーク`（画像・動画の URL を
  貼り付け）/ `ローカル`（ドラッグ&ドロップまたはファイル選択。画像は WebP に変換、
  動画は元の形式を保持）/ `なし`（プレビューファイルを全て削除）。
  カルーセルで表示しているページがそのまま意味を持ちます: 保存すると、
  その画像がモデルの**第一プレビュー**（カードが表示する画像）になり、
  残りはその後に元の順序で続きます。
- **Description** — ヒント文のとなりの**編集（鉛筆）アイコン**を押すと Markdown
  テキストエリアが開き、フォーカスを外すと保存されます。

  ![Description 編集](screenshots/model-edit-description.png)

- **保存 / キャンセル** — 保存は 1 回の `PUT` を発行し、変わったもの
  （名前・種別・ディレクトリ・プレビュー・説明）だけが適用されます。
- **削除**（赤いゴミ箱） — 確認ダイアログの後、モデル**と**プレビューとノートを
  まとめて削除します。

## 6. モデルのダウンロード

ヘッダーの**ダウンロード一覧**を開き、以下を使います。

### ダウンロードタスクを作成

![ダウンロードタスク作成](screenshots/download.png)

1. **Civitai のモデルページ**・**HuggingFace の repo/blob/tree**・
   **直接ファイルリンク**（`.safetensors`・`.ckpt`・`.gguf` など）を貼り付け、
   Enter または検索アイコンを押します。
2. 直接リンクの場合は先に**モデル種別**を選ぶ必要があります（現在の ComfyUI に
   存在する種別のみ提示）。任意の**サブフォルダ**欄でより深く置けます。
3. Civitai / HF ページは 1 つ以上の**バージョン**と**ファイル**に解決されます。
   バージョンはツールバー、ファイルはエディタ内で選びます。

   ![解決結果](screenshots/download-resolved.png)

4. エディタでは保存先の種別/ディレクトリ、ファイル名（フォルダ指定可）、
   プレビュー画像、Markdown 説明を設定できます（Civitai / HF の説明はトリガーワードや
   YAML メタデータごとにあらかじめ入力されます）。プレビューはモデルページが
   提供する**ギャラリー全体**が保持され、カルーセルで選択中の画像が
   カードの第一プレビューになります。
5. **ダウンロード**でバックグラウンドタスクが開始します。プレビューは可能な限り
   ブラウザ側で取得し、ダメならサーバ側で取得します。どちらも失敗しても
   モデル本体はダウンロードされます（プレビュー無しになるだけ）。

### ダウンロード一覧

**外部ダウンロード**と**ローカルアップロード**の 2 セクション。各行にプレビュー
サムネイル、進捗バー、転送量/総量、速度が表示され、**一時停止 / 再開 / 削除**
できます。削除は途中ファイルとタスク管理情報を一緒に消します。一時停止した
ダウンロードは HTTP `Range` で再開されます。

> 進捗・一時停止・完了はウィンドウを閉じても維持されます。タスクはバックエンドに
> 生き、websocket でプッシュされます。

## 7. HuggingFace へのアップロード

先にトークンを設定します: **設定 → Model Manager Neo → API キー →
HuggingFace API キー**（または環境変数 `HF_TOKEN`）。

ヘッダーの**HuggingFace へアップロード**を開きます。

1. **モデル種別を選択** — 種別ごとのボタン。
2. **モデルを選択** — その種別のグリッド。選ぶと保存先パスがモデルの相対パスで
   自動入力されます。
3. **HuggingFace へアップロード**:

   ![HF アップロードフォーム](screenshots/hf-upload.png)

   - **リポジトリ ID** — `username/repo-name`。
   - **リポジトリが存在しない場合はプライベートで作成する** — _作成時にのみ_
     効きます。既存リポジトリの公開設定は変わりません。
   - **リポジトリ内の保存先パス** — リポジトリ内のディレクトリ + ファイル名。

**アップロード**を押すと要求は即座に返り、転送はバックグラウンドで走るため、
ウィンドウを閉じても転送はキャンセルされません。進捗表示は現在のフェーズ名を
出します。

| フェーズ          | 内容                                                                                                          |
| ----------------- | ------------------------------------------------------------------------------------------------------------- |
| `準備中…`         | トークン確認・リポジトリ確認・preupload 交渉                                                                  |
| `ハッシュ計算中…` | ローカル sha256 を計算（数 GB のモデルでは数分かかることも）。**この時点ではまだ 1 バイトも送信していません** |
| `アップロード中…` | 実転送。割合がライブで更新されます                                                                            |

![HF アップロード進捗](screenshots/hf-upload-progress.png)

### 完了時に出るメッセージ

| トースト                                                                    | 意味                                                                                                                                                                                     |
| --------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **成功** — `path -> repo`                                                   | 新しいコミットが作成され、バイトも転送された                                                                                                                                             |
| **HuggingFace 側に既存のデータです**                                        | 同一バイト列がリポジトリのオブジェクトストアに既にあったため転送は発生しません（`Upload 0 LFS files`）が、それを指す**新しいコミットは作成済み**。トーストにファイルへのリンクが付きます |
| **スキップしました** — 「'repo' に同一のファイルが既に存在します: <url> …」 | まったく同じファイルがそのパスに既にあります。HuggingFace は空コミットを拒否するため何もしていません。新しいコミットが欲しければ別の保存先パスを指定してください                         |
| **エラー**                                                                  | 転送失敗。メッセージにバックエンドの理由が入ります                                                                                                                                       |

## 8. ローカルファイルからのアップロード

**ダウンロード一覧 → ローカルファイルからアップロード**:

1. モデル種別を選び、
2. ツリーでフォルダ（またはサブフォルダ）を選び、
3. ファイルを選択します。

アップロードはダウンロード一覧に**ローカルタスク**として登録され、正確な進捗を
表示しつつ選択したフォルダへ完了します。保存先はサーバ側で検証されます
（任意パスへの書き込み・パス侵入は不可）。

## 8b. フィードバック・ギャラリー・ライトボックス

- **トースト**。すべての操作が結果を報告します: 成功(緑)/警告(琥珀)/エラー(赤)/
  情報(アクセント)。各トーストには重大度アイコン、色付きの左バー、右上の
  **閉じるボタン**があり、ダイアログより常に手前で右上に積層し、時間経過で
  自動消滅します。
  ![toasts](screenshots/toast-stack.png)
- **プレビューは全部保存**。ダウンロードも保存も、モデルのプレビュー画像を
  すべて保存します(`<name>.webp` / `<name>.preview.webp` / `<name>.preview2.webp` …)。
  保存時にカルーセルで選択中の画像が第一プレビュー（カードの表紙）になります。
- **ページ送り**。プレビューが2枚以上ある場合、プレビュー欄に **＜ / ＞
  ボタン**と `i / n` カウンタが表示されます(閲覧モードでも編集モードでも)。
- **ライトボックス**。プレビューをタップすると全画面表示。＜ / ＞ または
  矢印キーでページ送り、`Esc`・背景クリック・閉じるボタンで閉じます。
  ![lightbox](screenshots/lightbox.png)
- **環境変数のキー**。`private.key` が空で `HF_TOKEN` / `CIVITAI_API_KEY` が
  _export_ されている場合、存在するキーだけを `private.key` へ自動取り込みます。
- **大きすぎるアップロード**。ComfyUI サーバーの上限(`--max-upload-size`、
  既定 100 MB)を超えるファイルは、bare な「HTTP 413」ではなく、上限の
  引き上げ方を案内するトーストで報告されます。

## 8c. 複数選択と ZipNN 圧縮

### ファイルを選択

両レイアウトのツールバーに**ファイルを選択**トグル(リストチェックアイコン)が
あります。ON の間、すべてのカード/フォルダの左上に丸いチェックボックスが現れ、
カードをクリックすると開く代わりに選択されます。1件以上選択するとウィンドウ
下部に一括バーが表示されます:

- **ワークフローに追加** — 選択中のモデルごとにローダーノードを作成。選択中の
  _フォルダ_は中のモデルすべて(再帰的に)が対象;
- **削除** — Danger 確認の後、選択中のモデルを削除(プレビューとノートも含む)。
  選択中の_フォルダ_は再帰的に削除;
- **ZipNN バッチ**(フォルダ選択時) — ZipNN アートワークのボタン。選択フォルダを
  バッチ圧縮/解凍(下記);
- **ZipNN デルタ圧縮**(プレーンなモデルをちょうど2件選択時) — ベース/ファイン
  テューンの選択ダイアログを開く(下記);
- **スター**(フォルダ選択時・アイコンのみ) — 選択フォルダがすべてスター済みの
  ときは黄色(押すとすべて解除)、それ以外はスター無しのフォルダのみに付与;
- **選択を解除** — すべて解除。モードを抜ける際も解除されます。

ZipNN バンドルフォルダ(`*_DeltaZNN` / 旧 `*_ZNN`)と通常のフォルダは同時選択できません。片方を
選択しようとするとバンドル側のチェックが外れ、警告トーストが出ます。

### ZipNN 圧縮

`.safetensors` モデルを開くと、プレビューと情報テーブルの間の隙間に
**ZipNN アートワークそのもののボタン**が表示されます(同梱 SVG が自前のガラス盤と
ダークモード版を描画し、ホバーで浮き上がり+明るく、ツールチップと aria-label で
説明)。押すと Danger には**しない**確認ダイアログが出て、その後バックグラウンドで
テンサル毎に圧縮します:

- 実行中、ボタンは**進捗バー**に置き換わります;
- 成功すると元ファイルは `<name>.znn.safetensors` に置き換わり、プレビューと
  ノートも追従してリネーム、グリッドは自動更新されます;
- 圧縮済みモデルを開くと同じボタンが**色が反転**した状態で**ZipNN 解凍**ラベルに
  なり、押すと確認の上で通常の `.safetensors` へ戻します。

圧縮済みモデルでは、情報テーブルの**ファイルサイズ**の 1 行が
**元のファイルサイズ** / **圧縮後のファイルサイズ** / **圧縮前サイズ比**の 3 行に
置き換わります(圧縮前のサイズは圧縮時にファイルのメタデータへ記録されます)。

圧縮ファイルは公式 ZipNN のレイアウト(`znn_compressed_vectors` メタデータ、
浮動小数点テンサルの Huffman 圧縮)に従うため、`zipnn_safetensors()` パッチ済みの
ローダーは透過的に読めます。圧縮は**可逆・無損失**で、`.znn.safetensors` が完全に
書き込まれた後にのみ元の `.safetensors` を削除し、失敗した場合は途中ファイルを
片付けます。

**インストール作業は不要です。** ZipNN は拡張機能内
([`third_party/`](../third_party/))に**同梱**されており、Linux x86_64
(CPython 3.10〜3.13)向けの**ビルド済み `zipnn_core` バイナリ**も含まれます。
これらの環境では、初回の圧縮は同梱パッケージと該当バイナリを import パスに
載せるだけで動作します ― **`pip install` も C コンパイラもネットワークも待ち時間も
ありません**。ビルド済みバイナリが一致しない場合(macOS、Windows、珍しい
アーキテクチャ、または非常に新しい CPython)のみ、同梱の C ソースから**一度だけ**
コアをビルドします。これには C コンパイラと Python ヘッダー(`Python.h`)が必要です。
このフォールバックビルドが失敗した場合、エラー
トーストに最初の重要行(全文は ComfyUI コンソール)と、不足している前提条件+
ディストリビューション別の修復コマンドが表示され、**再試行**アクションから
やり直せます。このビルドでコンパイラを自分で指定したい場合は、ComfyUI
起動前に `CC=/path/to/gcc` をエクスポートしてください。プラットフォーム/glibc の
対応範囲や、他のシステム向けバイナリの追加方法は
[`third_party/README.md`](../third_party/README.md) を参照してください。

### ZipNN バッチ圧縮（フォルダ単位）

フォルダを1つ以上選択して一括バーの **ZipNN アートワークボタン**を押すか、
フォルダカード右上のコーナーボタンを使います。確認の後、フォルダツリー内の
すべての `.safetensors` モデルが圧縮され(プレビューとノートも追従)、**バンドル
フォルダ `<name>_DeltaZNN` へ移動**します(空になった元フォルダは消滅)。バンドル
フォルダは封印されており、内部に置けるのは ZipNN の内容物(`*.znn.*` モデルと
`*.znn` デルタファイル)だけ(プレーンモデルのアップロード/ダウンロード/移動は
拒否)。バンドルの ZipNN ボタンは**反転表示**で、押すと**バッチ解凍** — 中身は元の
フォルダへ戻り、空になったバンドルフォルダは削除されます。デルタフォルダ
(`<base>_DeltaZNN`)もバンドル扱いで、反転ボタンが内部のファインチューンモデルを
まとめて復元します。モデル種別のルートフォルダ(`checkpoints` など)はバンドルを
**自分の中に**作ります(`<root>_DeltaZNN`。外に作ると ComfyUI のフォルダ対応から
外れるため)。方向は自動判定(未圧縮があれば圧縮、圧縮済みのみなら解凍)。旧バージョンの
`<name>_ZNN` バンドルも引き続き元の名前へ解凍されます。進捗リングには円内へ
パーセントが表示されます。
複数フォルダは1回の確認で順番に処理されます。

### ZipNN デルタ圧縮（ファインチューン）

プレーンな `.safetensors` モデルをちょうど2件(ベース+ファインチューン)選択して
**ZipNN デルタ圧縮**を押します。ダイアログでどちらが**ベースモデル**かを選ぶと、
もう一方がファインチューンとして扱われます。確認すると**差分だけ**が
`<base>_DeltaZNN/<ft>_delta_<base>.znn` に保存され(通常はファインチューンの
数%サイズ)、冗長なファインチューンファイルは削除されます。デルタのカードボタン
(反転アートワーク)はファインチューンをベースの隣へ**バイト完全一致**で復元し、
空になったデルタフォルダを削除します。復元にはベースモデルの現存が必要です。

## 9. 設定

ComfyUI の**設定 → Model Manager Neo**:

### API キー

- **HuggingFace API キー** / **Civitai API キー** — 拡張機能のとなりの
  `private.key` にローカル保存（UI ではマスク表示）。環境変数 `HF_TOKEN` /
  `CIVITAI_API_KEY` がフォールバックになります。旧バージョンで ComfyUI のユーザー
  設定に保存されていたキーは初回実行時に自動移行されます。

### モデル一覧

- **一覧から除外するモデル種別（カンマ区切り）** — グリッドとピッカーから非表示。
- **隠しファイル（. で始まる名前）を含める** — ツールバーの目アイコンと同じ。

### UI

- **カードサイズ / カードサイズマップ** — サイズピッカーの永続化用
  （非表示項目。カスタムサイズダイアログから編集）。
- **フラット表示** — 起動時の既定レイアウト。

## 10. 言語

UI は ComfyUI のロケール（**設定 → ComfyUI → Locale**）に従い、**English**・
**中文**・**日本語**の完全バンドルを同梱しています。地域・文字体系サブタグ
（`ja-JP`・`zh-Hant-TW` など）は基底言語へ畳まれ、それ以外は English に
フォールバックします。

## 11. トラブルシューティング

| 症状                                        | 原因 / 対処                                                                                                           |
| ------------------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| マネージャーのボタンが無い                  | 拡張機能が登録されていない。ComfyUI ログの import エラーと、フォルダ名が `ComfyUI-Model-Manager-Neo` であることを確認 |
| `HuggingFace token not set`                 | 設定（または `HF_TOKEN`）でトークンを設定し、ダイアログを開き直す                                                     |
| ダウンロードが始まらない                    | URL が認証を要求している可能性（Civitai の制限付きモデル）。Civitai キーを設定。タスク行にサーバのエラー文が出ます    |
| 「モデルの更新に失敗しました: PathIndex …」 | 選択した種別のフォルダがこのマシンに無い。ドロップダウンから実在する種別を選ぶ                                        |
| UI が素のグレーの箱に見える                 | 古い `web/` バンドルを見ています。開発時のみ `pnpm build` で再ビルド                                                  |
| プレビューが NO PREVIEW                     | プレビューファイルがありません。編集モードで設定してください                                                          |
