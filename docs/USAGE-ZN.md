> 文中截图位于 [`docs/screenshots/`](screenshots/)（各文件清单见

ComfyUI‑Model‑Manager‑Neo 是一个为 ComfyUI 增加模型**浏览、下载、上传、编辑**
能力的自定义节点。它完全运行在 ComfyUI 进程内部：后端是 ComfyUI 服务器中的一组
`aiohttp` 路由，前端是注入页面的单个打包 Vue 3 应用。

## 1. 安装

```bash
cd ComfyUI/custom_nodes
git clone https://github.com/rikunarita/ComfyUI-Model-Manager-Neo.git
```

重启 ComfyUI。Python 依赖（`huggingface_hub`、`hf_xet`、`markdownify`）会在首次
启动时自动安装；Web 打包产物随仓库一同提供，因此**运行不需要 Node.js**。

手动安装：下载仓库压缩包，解压到 `ComfyUI/custom_nodes/`，并确保文件夹名为
`ComfyUI-Model-Manager-Neo`。

## 2. 打开管理器

共有四个入口，行为完全相同：

| 入口                              | 位置                             |
| --------------------------------- | -------------------------------- |
| **顶栏「Model Manager Neo」按钮** | ComfyUI 顶栏（设置齿轮旁）       |
| **旧版菜单按钮**                  | 旧式菜单容器（若你的前端仍保留） |
| **Extensions 菜单**               | `Extensions → Model Manager Neo` |
| **命令面板**                      | `Comfy.ModelManager.Open` 命令   |

管理器是**非模态**窗口：它浮在 ComfyUI 之上，但画布保持完全可交互，因此可以一边
浏览一边把模型拖到图上。窗口可用标题栏拖动、任意边角调整大小，⤢ 按钮可最大化。
可同时打开多个窗口，点击某个窗口会把它带到最前。

> 加载指示**只作用于所属面板**：请求进行中时只有该窗口被压暗模糊，画布、顶栏与
> 其他窗口仍然可用。
>
> ![面板内加载](screenshots/loading-panel.png)

## 3. 两种布局

用标题栏第一个按钮（网格 ⇄ 文件夹）切换；默认布局可在
**设置 → Model Manager Neo → 外观 → 展平布局** 中预选。

### 展平布局

把所有类型的所有模型放在一个网格里，并带工具栏：

- **搜索** — 多关键词为 AND 关系，`*` 为通配符（`*anime*` 匹配任何包含 anime
  的名字）。关键词匹配文件名**或**子文件夹。
- **类型筛选** — `全部` 或某一个模型类型。
- **排序** — 名称 / 最大 / 最新创建 / 最新修改 / **最近使用**（打开模型或加入图时记录）。
- **卡片尺寸** — 超大 / 大 / 中 / 小，或**自定义尺寸**（宽高滑块对话框，保存到
  ComfyUI 设置）。

![展平布局](screenshots/view-flat-dialog.png)

### 文件夹布局

带面包屑的文件管理器式树（每级带一个小文件夹图标）。双击文件夹进入，用面包屑或 ↑
按钮返回。右键模型弹出上下文菜单（**打开**）。面包屑会始终保留当前所在文件夹的可读
显示：窗口变窄时先省略中间层级，工具栏则与展平布局遵循同一响应式规则纵向堆叠，
而不会裁掉任何控件。

![文件夹布局](screenshots/view-folders-dialog.png)

搜索框旁是**添加文件夹**按钮（文件夹加号图标）：输入任意名称即在当前浏览的
目录中创建文件夹（以 `_ZNN` / `_DeltaZNN` 结尾的名称为 ZipNN 保留）。搜索框旁
还有**排序**与**卡片尺寸**选择器：文件夹视图的设计是"展平视图限定到单个文件夹，
再加上文件夹专属功能（返回上级、创建文件夹、文件夹压缩等）"，因此模型卡片在两种
布局中的外观与行为完全一致——包括悬停时出现的添加节点/复制/工作流/模型页面按钮列。

两种布局都可用标题栏的眼睛按钮切换**显示/隐藏隐藏文件**（以 `.` 开头的文件或文件夹）。

## 4. 模型卡片

![模型卡片](screenshots/view-flat.png)

- **预览** — 图片或循环视频；没有预览的模型显示玻璃质感的 **NO PREVIEW** artwork。
- **角标**（右下） — 模型类型与文件大小，随卡片尺寸缩放。
- **星标开关**（右上，每张卡片都有） — 未加星标时为轮廓星，已加星标时为黄色实心
  星；点击切换；已加星标的模型/文件夹始终排在最前。
- **ZipNN 角落按钮**（右上、星标旁） — ZipNN artwork 本身：单击即压缩（已压缩则反色
  显示并解压），带同样的确认与进度；文件夹卡片上则执行批量压缩/解压；任务运行中
  （单发/批量/增量）按钮显示圆环进度。
- **文件夹卡片** — 手绘玻璃文件夹；指针停留一秒后打开，离开一秒后合上，
  匆匆掠过不会触发。类型根卡片还显示**该类型的合计大小**。
- **重复警告** — 记录的 SHA256 与库中另一文件一致时，详情窗口以红色警告显示
  重复文件的路径。
- **悬停操作**（展平布局、大卡片） — **添加节点**、**复制节点**、**从预览载入工作流**、
  **打开模型页**（平台已知时，按钮以该平台 logo 为背景）。
- **拖拽到图** — 把任意卡片拖到画布：
  - 空白画布：创建对应的加载器节点并选好模型
  - 已有节点之上：填入匹配的 combo 输入
  - 把 _embedding_ 拖到文本区：追加 `(embedding:name:1.0)`
  - 拖拽**预览图**：载入其中内嵌的工作流
- **双击 / 单击** — 打开模型详情窗口。
- **工具提示** — 悬停卡片显示绝对路径。

## 5. 模型详情与编辑

![模型详情](screenshots/model-info.png)

窗口显示预览（多个预览时为轮播）、基本信息表和两个标签页。

| 行                             | 含义                                             |
| ------------------------------ | ------------------------------------------------ |
| 类型                           | ComfyUI 的模型文件夹组                           |
| **目录**                       | **带结尾 `/`** 的绝对目录，例如 `…/models/unet/` |
| 文件名                         | 不含扩展名的名字                                 |
| 文件大小 / 创建时间 / 更新时间 | 文件系统信息                                     |

### 查看

- **Description 标签** — 渲染保存在模型旁 `*.md` 文件中的 Markdown，链接在新标签打开。
- **Information 标签** — 汇总模型所记录全部信息的表格（默认只读；编辑模式下铅笔
  按钮**在警告之后**打开编辑，保存表单时重写笔记的 front-matter）：笔记开头的 YAML
  front-matter（Civitai / HuggingFace 下载写入的内容）会被解析为作者、基础模型、
  全部哈希（`AutoV1` … `SHA256_12`）、格式与精度、模型平台、可点击的模型页链接
  以及**所有**预览图 URL；解析器不认识的键按原样列在表格末尾。没有 front-matter
  的模型则原样显示直接从 safetensors 头读出的 `__metadata__`（没有任何后台扫描或
  缓存）。操作行中的**打开模型页**按钮与卡片悬停列中的同名按钮一样：只要笔记记录了
  来源平台，就以该 hub（Civitai / Hugging Face）的 logo 作为按钮背景。

### 编辑

点击**铅笔**进入编辑模式（窗口变为表单）：

![编辑模式](screenshots/model-edit.png)

- **模型类型** — 下拉只列出当前 ComfyUI 实际存在文件夹的类型。
- **目录** — 只读字段加**文件夹按钮**，后者打开一个嵌套的文件夹选择对话框，
  内含所有基础路径与子文件夹的树：

  ![文件夹选择](screenshots/folder-picker.png)

- **文件名** — 支持**文件夹前缀**。输入 `subfolder/my-model` 后保存，模型会被放入
  `…/models/unet/subfolder/`（缺少的文件夹会自动创建）。`\ : * ? " < > |` 以及空、
  `.`、`..` 段会被拒绝，后端还会再次做路径穿越校验。
- **预览** — `默认`（轮播）/ `网络`（粘贴图片或视频 URL）/ `本地`（拖放或选择文件；
  图片转 WebP，视频保留原格式）/ `无`（删除全部预览文件）。编辑模式的缩略图条可管理
  图集（选择主预览、左右移动、删除单张）；保存时停留的那一页成为卡片的**主预览**。
- **Description** — 点击提示文字旁的**编辑（铅笔）图标**打开 Markdown 文本框，
  文本框失焦即保存：

  ![Description 编辑](screenshots/model-edit-description.png)

- **保存 / 取消** — 保存只发一次 `PUT`，只有真正改动的字段
  （名称、类型、目录、预览、描述）会被应用。
- **删除**（红色垃圾桶） — 经确认对话框后，连同预览与说明文件一起删除模型。

## 6. 下载模型

打开标题栏的**下载列表**，然后：

### 创建下载任务

![创建下载任务](screenshots/download.png)

1. 粘贴 **Civitai 模型页**、**HuggingFace 的 repo/blob/tree** 或**直接文件链接**
   （`.safetensors`、`.ckpt`、`.gguf` 等），按 Enter 或搜索图标。
2. 直接链接必须先选择**模型类型**（只提供当前 ComfyUI 存在的类型）；可选的
   **子文件夹**栏可把文件放得更深。
3. Civitai / HF 页面会解析出一个或多个**版本**与**文件**：版本在工具栏选，
   文件在编辑器里选。

   ![解析结果](screenshots/download-resolved.png)

4. 编辑器中可设置目标类型/目录、文件名（可带文件夹前缀）、预览图与 Markdown 描述
   （Civitai / HF 的描述会预填，包含触发词与 YAML 元数据）。模型页提供的**整组预览图**
   都会保留，轮播中选中的那张会成为卡片的主预览。
5. **下载**启动后台任务。预览尽可能在浏览器侧获取，失败则改由服务器侧获取；两者都
   失败时模型仍然下载，只是没有预览。对话框显示目标卷的**可用空间**，不足时警告
   （后端也会拒绝）。

### 下载列表

分为**外部下载**与**本地上传**两节，每行显示预览缩略图、进度条、已传/总量与速度，
并提供**暂停 / 恢复 / 删除**。删除会清掉未完成文件与任务记录；暂停的下载通过
HTTP `Range` 断点续传。

> 进度、暂停与完成在关闭窗口后依然有效：任务活在后端，通过 websocket 推送。

## 7. 上传到 HuggingFace

先设置令牌：**设置 → Model Manager Neo → 密钥 → HuggingFace API 密钥**
（或导出环境变量 `HF_TOKEN`）。

打开标题栏的**上传到 HuggingFace**：

1. **选择模型类型** — 每个类型一个按钮。
2. **选择模型** — 该类型的网格；选中后保存路径自动填为模型的相对路径。
3. **上传到 HuggingFace**：

   ![HF 上传表单](screenshots/hf-upload.png)

   - **仓库 ID** — `username/repo-name`。
   - **仓库不存在时创建为私有仓库** — *只在创建时*生效；已有仓库保持其原有可见性。
   - **仓库内目标路径** — 仓库内的目录 + 文件名。

点击**上传**后请求立即返回，传输在后台进行，因此关闭窗口不会取消传输。进度读数会
显示当前阶段：

| 阶段          | 含义                                                                        |
| ------------- | --------------------------------------------------------------------------- |
| `准备中…`     | 令牌校验、仓库查询、preupload 协商                                          |
| `计算校验和…` | 计算本地 sha256（数 GB 的模型可能要几分钟）；**此时还没有任何字节离开本机** |
| `上传中…`     | 真实传输，百分比实时更新                                                    |

![HF 上传进度](screenshots/hf-upload-progress.png)

### 完成时可能出现的提示

| 提示                                                    | 含义                                                                                                                                    |
| ------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| **成功** — `path -> repo`                               | 已创建新提交且传输了字节                                                                                                                |
| **HuggingFace 已存储该内容**                            | 相同字节已存在于仓库对象存储中，因此 HuggingFace 未传输任何数据（`Upload 0 LFS files`），但**已创建指向它们的新提交**；提示中附文件链接 |
| **已跳过** — 「'repo' 中已存在完全相同的文件: <url> …」 | 同一路径已有完全相同的文件；HuggingFace 拒绝空提交，因此什么都没做。想产生新提交请换一个目标路径                                        |
| **错误**                                                | 传输失败，消息中带后端原因                                                                                                              |

## 8. 从本地文件上传

**下载列表 → 从本地文件上传**：

1. 选择模型类型，
2. 在树中选择文件夹（或子文件夹），
3. 选择文件。

上传会在下载列表中注册为**本地任务**，带精确进度，并落入所选文件夹。目标路径在
服务器侧校验（禁止任意写入与路径穿越）。

## 9. 反馈、图集与灯箱

- **提示条**。所有操作都会报告结果：成功(绿)/警告(琥珀)/错误(红)/信息(强调色)。
  每条提示带严重度图标、着色左栏和右上角的**关闭按钮**，堆叠在所有对话框之上的
  右上角，并在寿命结束后自动消失。
  ![toasts](screenshots/toast-stack.png)
- **预览全部保存**。下载与保存会保留模型的全部预览图
  (`<name>.webp` / `<name>.preview.webp` / `<name>.preview2.webp` …)。
  保存时轮播选中的图片即为主预览（卡片的封面图）。
- **翻页**。当模型有多张预览时，预览区域会显示 **＜ / ＞ 按钮**和 `i / n`
  计数器（查看模式与编辑模式都有）。
- **灯箱**。点按预览即全屏打开；＜ / ＞ 或方向键翻页，`Esc`、点击背景或关闭
  按钮退出。
  ![lightbox](screenshots/lightbox.png)
- **环境变量密钥**。当 `private.key` 为空且导出了 `HF_TOKEN` /
  `CIVITAI_API_KEY` 时，仅把环境中实际存在的密钥自动写入 `private.key`。
- **超大上传**。超过 ComfyUI 服务器上传上限(`--max-upload-size`，默认 100 MB)
  的文件会以提示条说明如何提高上限，而不是裸的「HTTP 413」。

## 10. 多选与 ZipNN 压缩

### 选择文件

两种布局的工具栏都有**选择文件**开关(列表勾选图标)。开启后每张卡片/文件夹左上
角出现圆形复选框；点击卡片变为勾选而不是打开。选中至少一项后窗口底部出现批量栏:

- **添加到工作流** — 为每个选中模型创建一个加载器节点；选中的_文件夹_会递归
  展开为其中的全部模型;
- **删除** — 经 Danger 确认后删除所有选中模型(含预览与说明)；选中的_文件夹_
  将被递归删除;
- **ZipNN 批量**（选中文件夹时） — ZipNN artwork 按钮：批量压缩/解压所选文件夹（见下）;
- **ZipNN 增量压缩**（恰好选中两个普通模型时） — 打开基础/微调选择对话框（见下）;
- **上传到 HuggingFace**（选中文件夹时） — 通过同一个上传对话框批量上传所选文件夹内的
  全部模型（保留子文件夹结构）;
- **星标**（选中文件夹时，仅图标） — 所选文件夹全部已加星标时为黄色（按下全部
  取消）；否则仅为未加星标的文件夹加星标;
- **清除选择** — 取消全部勾选；退出该模式时也会清除。

ZipNN 打包文件夹(`*_DeltaZNN` / 旧 `*_ZNN`)与普通文件夹不能同时选择：尝试混选时打包文件夹会被
自动取消勾选并弹出警告提示。

### ZipNN 压缩

打开 `.safetensors` 模型时，预览与信息表之间的空隙处就是 **ZipNN 图标本身构成的按钮**
(自带 SVG 会绘制自己的玻璃面板与深色模式版本，悬停时上浮并变亮，工具提示与 aria-label
说明作用)。点击后弹出
**非 Danger** 的确认框，随后在后台逐张量压缩:

- 运行期间按钮替换为**进度条**;
- 成功后原文件替换为 `<name>.znn.safetensors`，预览与说明随之改名，网格自动刷新;
- 打开已压缩模型时同一按钮**颜色反转**并显示 **ZipNN 解压**，点击确认后恢复为普通
  `.safetensors`。

已压缩模型的信息表还会把单行的**文件大小**替换为三行：**原文件大小**、
**压缩后文件大小**与**占原大小比例**（压缩前的大小在压缩时记录于文件元数据中）。

压缩文件遵循官方 ZipNN 布局(`znn_compressed_vectors` 元数据、浮点张量 Huffman
压缩)，因此经 `zipnn_safetensors()` 补丁的加载器可透明读取。压缩是**无损且可逆**的：
只有在 `.znn.safetensors` 完整写入后才会删除原始的 `.safetensors`，失败时会清理
未完成的产物。

**无需安装步骤。** ZipNN 已**随扩展内置**于 [`third_party/`](../third_party/)，
并附带 Linux x86_64(CPython 3.10–3.14)的**预编译 `zipnn_core` 二进制**。在这些平台上，
首次压缩只是把内置包与对应二进制加入导入路径即可工作——**无需 `pip install`、无需
C 编译器、无需联网、无需等待**。只有当没有匹配的预编译二进制时(macOS、Windows、
少见架构，或非常新的 CPython)，才会从内置 C 源码**一次性**构建核心，这需要 C 编译器
与 Python 头文件(`Python.h`)。若该回退构建失败，错误提示会显示第一条关键信息
(完整输出在 ComfyUI 控制台)、缺失的依赖以及对应发行版的修复命令，并提供**重试**操作。
如需为该构建自行指定编译器，请在启动 ComfyUI 前导出 `CC=/path/to/gcc`。平台/glibc
覆盖范围以及如何为其他系统添加二进制，见
[`third_party/README.md`](../third_party/README.md)。

### ZipNN 批量压缩（文件夹）

选中一个或多个文件夹后按下批量栏中的 **ZipNN artwork 按钮**（或使用文件夹卡片
右上角按钮）。确认后，文件夹树内所有 `.safetensors` 模型被压缩（预览与说明随
模型迁移），所有压缩结果**移入打包文件夹 `<name>_DeltaZNN`**（清空的原始文件夹
消失）。打包文件夹是密封的：内部只允许 ZipNN 内容（`*.znn.*` 模型与 `*.znn` 增量
文件；普通模型的上传/下载/移入会被拒绝）。打包文件夹的 ZipNN 按钮**反色**显示，
按下即**批量解压**：内容移回其命名所源的文件夹，清空的打包文件夹被删除；增量文件夹
（`<base>_DeltaZNN`）同属打包文件夹，反色按钮会一次性还原其中的全部微调模型。
模型类型**根文件夹**（如 `checkpoints`）的打包文件夹生成在**其内部**
（`<root>_DeltaZNN`，因为根目录的兄弟目录不在 ComfyUI 的目录映射内），方向自动
判定：有未压缩模型则压缩，仅剩压缩包则解压；旧版本生成的 `<name>_ZNN` 仍可解压回
原名；任务进行中按钮显示圆环且**环内带百分比**。多个文件夹在一次确认后顺序执行。

### ZipNN 增量压缩（微调模型）

恰好选中两个普通 `.safetensors` 模型（基础 + 微调）后按下 **ZipNN 增量压缩**。
对话框中指定哪一个为**基础模型**，另一个作为微调模型。确认后仅保存**差值**到
`<base>_DeltaZNN/<ft>_delta_<base>.znn`（通常仅为微调模型的百分之几），并删除
冗余的微调文件。增量文件的卡片按钮（反色 artwork）会把微调模型**逐字节精确**
恢复到基础模型旁边，并在清空后删除增量文件夹。恢复需要基础模型仍然存在。

## 11. 设置

ComfyUI **设置 → Model Manager Neo**：

### 密钥

- **HuggingFace API 密钥** / **Civitai API 密钥** — 保存在扩展目录旁的 `private.key`
  中（界面打码显示），并可用 `HF_TOKEN` / `CIVITAI_API_KEY` 环境变量兜底。旧版本保存
  在 ComfyUI 用户设置中的密钥会在首次运行时自动迁移。

### 模型列表

- **排除模型类型（使用英文逗号隔开）** — 从网格与选择器中隐藏这些类型。
- **包含隐藏文件（以 . 开头的文件或文件夹）** — 与工具栏眼睛按钮相同。

### 外观

- **卡片尺寸 / 卡片尺寸映射** — 尺寸选择器的持久化项（隐藏项；请通过自定义尺寸
  对话框修改）。
- **展平布局** — 打开时的默认布局。
- **ZipNN → 按未使用天数自动压缩**（0=关闭）、**下载后自动压缩**、**下载 → 提示执行时
  暂停**（执行结束后恢复）。

## 12. 语言

界面跟随 ComfyUI 的语言设置（**设置 → ComfyUI → Locale**），内置 **English**、
**中文**、**日本語** 三套完整文案。地区/文字子标签（`ja-JP`、`zh-Hant-TW` 等）会归并
到其基础语言，其余回落到 English。

## 13. 故障排查

| 症状                          | 原因 / 处理                                                                                 |
| ----------------------------- | ------------------------------------------------------------------------------------------- |
| 管理器按钮不见了              | 扩展未注册。检查 ComfyUI 日志中的 import 错误，并确认文件夹名为 `ComfyUI-Model-Manager-Neo` |
| `HuggingFace token not set`   | 在设置（或 `HF_TOKEN`）中设置令牌后重新打开对话框                                           |
| 下载不开始                    | URL 可能需要鉴权（Civitai 受限模型）——设置 Civitai 密钥；任务行会显示服务器错误文本         |
| 「更新模型失败: PathIndex …」 | 所选类型在本机没有文件夹——从下拉中选择真实存在的类型                                        |
| 界面是灰色原生控件            | 看到的是过期的 `web/` 打包产物；开发时请用 `pnpm build` 重新构建                            |
| 预览显示 NO PREVIEW           | 模型没有预览文件；在编辑模式中设置一个                                                      |
