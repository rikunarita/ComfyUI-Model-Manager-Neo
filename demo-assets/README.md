# `demo-assets/` — デモアセットマニフェスト

このフォルダは、README と各使い方ガイドが参照するスクリーンショット・画面収録を
まとめて管理する場所です。表中の「内容」は、各ファイルが何を映しているべきか
（＝実働 ComfyUI ウィンドウからの撮り直し手順の目安）を正確に定義します。
まだ差し替えられていないファイルは開発セッションの仮キャプチャであり、
このマニフェストに従って本キャプチャへ置き換えてください。

> **撮影のしかた。** 拡張機能を読み込んだ ComfyUI を起動し、下表の「内容」に
> 合わせて手動で撮影します。テーマは**ダーク**推奨（UI はホストのパレットに
> 追従し、グラス表現はダークで最も映えます）。窓幅は統一感のため
> **約 1600 px** を目安にしてください。

## 撮影のヒント

- ComfyUI は**ダークテーマ**で実行してください。UI はホストパレットに追従し、
  ガラス表現はダークで最も読みやすくなります。
- 窓幅は **約 1600 px** で統一し、GIF はファイルサイズを抑えるため
  8〜12 fps 程度で書き出してください。
- ライブラリは「プレビュー**あり**」と「プレビュー**なし**」のモデルを
  最低 1 つずつ用意すると、NO‑PREVIEW アートワークも一緒に写せます。
- ダイアログの角は好みに合わせてトリミング/丸めして構いませんが、
  ツールバーとチップは読める大きさを保ってください。

## `hero.gif` の生成コマンド

`hero.webm` から GIF を生成するときは次のコマンドを使います:

```bash
ffmpeg -vf "fps=10,scale=900:-1:flags=lanczos,split[s0][s1];[s0]palettegen[p];[s1][p]paletteuse" \
  -i hero.webm hero.gif
```

すべてのファイルを差し替えたあとは、このマニフェストを削除しても、
今後の貢献者向けドキュメントとして残しても構いません。
