# `demo-assets/` — デモアセットマニフェスト

このフォルダは、README と各使い方ガイドが参照するスクリーンショット・画面収録を
まとめて管理する場所です。**静止画は AVIF、ツアー録画は WebM** です
（モダンブラウザを前提とし、フォールバックは持ちません）。表中の「内容」は、
各ファイルが何を映しているべきか（＝実働 ComfyUI ウィンドウからの撮り直し
手順の目安）を正確に定義します。まだ差し替えられていないファイルは開発
セッションの仮キャプチャまたはプレースホルダーであり、このマニフェストに
従って本キャプチャへ置き換えてください。

> **撮影のしかた。** 拡張機能を読み込んだ ComfyUI を起動し、下表の「内容」に
> 合わせて手動で撮影します。テーマは**ダーク**推奨（UI はホストのパレットに
> 追従し、グラス表現はダークで最も映えます）。窓幅は統一感のため
> **約 1600 px** を目安にしてください。静止画は撮影後 **AVIF** へ、
> 録画は **WebM** へ書き出してください。

## 今回の整理で削除したファイル

- `hero.gif` — ツーヤーは WebM のみに統一（README は `hero.webm` を直接埋め込み）。
- `download.png` — `download-resolved.avif` へ統合（解決済みエディタの方が
  フローを完全に説明できるため）。
- `model-edit-description.png` / `toast-stack.png` / `lightbox.png` —
  本文の説明で十分に伝わるため、ドキュメント側の参照とともに削除。
- 全静止画の `.png` → `.avif` 移行（モダンブラウザ前提・フォールバックなし）。

## 撮影のヒント

- ComfyUI は**ダークテーマ**で実行してください。UI はホストパレットに追従し、
  グラス表現はダークで最も読みやすくなります。
- 窓幅は **約 1600 px** で統一してください。
- ライブラリは「プレビュー**あり**」と「プレビュー**なし**」のモデルを
  最低 1 つずつ用意すると、NO‑PREVIEW アートワークも一緒に写せます。
- ダイアログの角は好みに合わせてトリミング/丸めして構いませんが、
  ツールバーとチップは読める大きさを保ってください。
- 静止画は **AVIF**（品質 80 以上推奨）、録画は **WebM**（準可逆寄り）で
  書き出してください。GIF は使用しません。

すべてのファイルを差し替えたあとは、このマニフェストを削除しても、
今後の貢献者向けドキュメントとして残しても構いません。
